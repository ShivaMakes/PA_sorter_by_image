# Cushion Cover Sorter

A custom image sorting tool built with Tkinter for visually arranging and managing product images like cushion covers.

## ✨ Features
- Drag-and-drop reordering
- Multi-selection mode with batch delete
- Load images by filename (pasted or selected)
- Full image preview on double click
- Undo last action
- Save sorted order to `.txt` file

## 📦 Requirements
- Python 3.x
- Pillow

Install required packages:
```bash
pip install pillow
